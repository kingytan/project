A curriculum that takes you from ordinary user to the top 1%: someone with a complete mental model of Claude, every product surface, and a compounding personal setup that improves weekly.

Built August 2026. Product details drift; the mental models don't. Each module ends with exercises because reading about Claude is not using Claude.

## How to use this repo

- This repo is itself a training ground: it has a `.claude/skills/` folder you will grow, and every module's exercises can run right here in Claude Code.
- Work the modules in order the first time; after that, use them as reference.
- The habit that matters more than any module: when Claude does something well, capture it (as a skill, a CLAUDE.md line, or a saved prompt). Compounding beats cramming.

## Staying current

The top 1% stay current on ~15 minutes a month:

- [anthropic.com/news](https://www.anthropic.com/news) — model and product announcements
- [docs.claude.com](https://docs.claude.com) — platform docs and release notes
- [code.claude.com/docs](https://code.claude.com/docs) — Claude Code docs and changelog
- [support.claude.com](https://support.claude.com) — plan features and limits
- Ask Claude itself: "what changed in Claude Code this month?" (it can read its own changelog)
