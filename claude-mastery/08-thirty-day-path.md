# Module 08 — The 30-Day Path

Knowledge doesn't compound; habits do. This is a day-by-day installation plan: ~20–40 minutes a day, each day producing something you keep. Adjust freely, but keep the weekly arcs: **Week 1 foundations → Week 2 daily integration → Week 3 agents & automation → Week 4 compounding systems.**

## Week 1 — Foundations (see Modules 00–02)

- **Day 1.** Inventory. List every task you did this week that felt repetitive or mechanical, work and personal. Mark the three most frequent. This list drives the whole month.
- **Day 2.** Prompting reset. Take yesterday's #1 task; run it with a full brief (outcome, audience, three checkable criteria, one example). Compare against your old way.
- **Day 3.** Verification loops. Re-run the same task adding "score your output against the criteria, then revise once." Notice the delta. This trick now goes in everything.
- **Day 4.** Meet skills. Read Module 01. Dissect `.claude/skills/stop-slop/` in this repo. No building yet, just architecture.
- **Day 5.** Build skill #1 with `/skill-creator` from your day-1 list. Test its trigger three ways.
- **Day 6.** Personal-life day. Give Claude a real personal task with full context (trip, meal plan, budget review, big purchase research). Same craft applies off the clock.
- **Day 7.** Review. What surprised you? Ask Claude: "Here are my prompts from this week [paste]. Critique them and rewrite the worst two."

## Week 2 — claude.ai as daily driver (Module 03)

- **Day 8.** Create your first Project for a real recurring context (a client, a course, a team). Write project instructions; add 3–5 knowledge files.
- **Day 9.** Live in that Project all day. Note every instruction you repeat; move it into project instructions at day's end.
- **Day 10.** Memory audit. Review what Claude remembers about you; correct and prune it. Set up work/personal separation if offered.
- **Day 11.** Connectors. Wire one real data source (Drive, calendar, email). Run one task that was impossible before it.
- **Day 12.** Research mode. Give a genuinely hard research question from your real life; compare against what you'd have produced in the same hour.
- **Day 13.** Artifacts + files. Have Claude build one interactive artifact and one real document (spreadsheet or deck) you'll actually use.
- **Day 14.** Review. Skill #2 from any repetition you noticed this week.

## Week 3 — Claude Code and delegation (Module 04)

- **Day 15.** Setup. Install/open Claude Code on a real project. `/init`, then trim CLAUDE.md to only what it couldn't infer.
- **Day 16.** First real delegation: a small but real task, plan mode first, tests as verification. Review like a PR.
- **Day 17.** Permissions. Add your allowlist (or run `/fewer-permission-prompts`). Add one hook (auto-format on edit).
- **Day 18.** Subagents. Run one exploration through a subagent; do one adversarial review of a diff with a fresh session.
- **Day 19.** MCP. Connect one external system (browser via Playwright, GitHub, your issue tracker). Use it in a real task.
- **Day 20.** Parallel day. Two sessions (worktrees or cloud), two independent tasks, one afternoon. Your job: briefs and reviews.
- **Day 21.** Review. Skill #3. Bank every correction from this week into CLAUDE.md.

## Week 4 — Automation and compounding (Modules 05–07)

- **Day 22.** Cloud sessions. Send a long task to claude.ai/code from your phone or browser; check in twice; review at the end.
- **Day 23.** Schedule something. One Cowork scheduled task or Claude Code Routine that runs without you (morning brief, weekly digest, inbox triage).
- **Day 24.** Cowork day. Hand it an outcome that costs you 45 minutes by hand (organize a folder tree, turn raw notes into a findings doc, assemble a report from three files). Walk away. Judge the deliverable.
- **Day 25.** API taste (optional but eye-opening). In the Console workbench, run one of your skills' jobs as an API call; understand what you'd automate if you shipped it.
- **Day 26.** The audit. Run Module 07's self-audit. Score honestly.
- **Day 27.** Fix your two lowest audit scores with a system, not an intention (a skill, a hook, a Routine, a Project).
- **Day 28.** Teach-back. Explain skills + verification loops + surface choice to a colleague or friend in 10 minutes. Teaching exposes the gaps.
- **Day 29.** Meta-loop. Paste your month's usage patterns into Claude: "What would a top 1% user do differently? Draft the three highest-impact changes."
- **Day 30.** Lock the cadence. Calendar three recurring slots: weekly 15-min capture review ("what should become a skill?"), monthly self-audit, monthly 15-min changelog catch-up.

## After day 30

You're maintaining a system now, not learning a tool. The flywheel: **use → notice friction → capture → friction gone forever.** Protect the weekly capture review above all; it's the engine. Everything else is optional.
